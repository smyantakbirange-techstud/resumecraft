# ResumeCraft — Free Resume Builder

A responsive, front-end resume builder website built with plain HTML, CSS, and JavaScript.

## Features
- Responsive landing page
- Editable personal, education, skills, project and certification fields
- Live resume preview
- Classic, Modern, and Minimal resume styles
- Print / Save as PDF using the browser's print dialog
- No login, backend, or paid service required
- Form data stays in the current browser page; this demo does not upload it to a server

## Run locally
1. Extract the ZIP file.
2. Open the extracted `ResumeCraft` folder.
3. Double-click `index.html` to open it in a browser.

You can also open the folder in Visual Studio Code and edit `index.html`, `styles.css`, and `script.js`.

## Download your resume as PDF
1. Fill in the form.
2. Click **Download PDF**.
3. In the print dialog, choose **Save as PDF** as the destination/printer.
4. Click **Save**.

## Free hosting
### GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. `resumecraft`.
3. Upload the contents of this folder (`index.html`, `styles.css`, `script.js`, `README.md`).
4. In repository **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site; the URL appears in Settings → Pages.

### Netlify
You can also sign in to Netlify and deploy the extracted folder using its current manual deploy workflow. Free-plan availability and limits may change.

## Before launching publicly
- Replace all example/sample resume information and review the wording.
- Add your own About, Privacy, and Contact pages if needed for a public business.
- Test the site on mobile and desktop.
- Do not collect visitors' sensitive personal information unless you have a clear privacy policy and appropriate security.
- This starter project does not include server-side storage, accounts, AI writing, payment processing, or ad integration.
